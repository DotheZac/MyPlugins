# Portal Effect

Unreal Engine 5.7에서 사용하는 포탈 비주얼 이펙트 에셋 플러그인입니다.

- 버전: `1.0`
- 제작자: `DotheZac`
- 유형: Content 전용 플러그인

## 주요 구성

- 포탈 기본 머티리얼
- 포탈 머티리얼 인스턴스
- 노이즈, 그라디언트, 플레어 텍스처

## 주요 에셋

- `M_Portal`
- `M_Portal1`
- `M_Portal_Inst`
- `M_Portal1_Inst`

## 사용 방법

플러그인을 활성화한 후 Content Browser에서 `PortalEffect Content`를 표시하여 필요한 머티리얼 또는 머티리얼 인스턴스를 사용합니다.
