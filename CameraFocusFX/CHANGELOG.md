# Changelog

## 1.1.3

- 기본 `CameraFocusFXPreset` Data Asset의 설정을 조정했습니다.

## 1.1.2

- Data Asset과 컴포넌트의 편집 옵션에 한국어 툴팁을 추가했습니다.
- `Focus FStop`의 편집 및 런타임 범위를 `0.01~32.0`으로 확장했습니다.

## 1.1.1

- 플러그인 내부 `Content` 폴더와 에셋 저장을 지원하도록 `CanContainContent`를 활성화했습니다.

## 1.1.0

- 재사용 가능한 `CameraFocusFXPreset` Data Asset을 추가했습니다.
- BeginPlay 자동 적용과 런타임 `ApplyPreset` 교체를 지원합니다.

## 1.0.0

- SpringArm 길이에 따른 자동 집중 효과 강도 계산을 추가했습니다.
- 비네트와 Depth of Field 효과를 보간 적용합니다.
- 로컬 플레이어 전용 적용과 원래 Post Process 설정 복원을 지원합니다.
- 블루프린트 수동 강도 제어 및 대상 컴포넌트 자동 탐색을 지원합니다.
