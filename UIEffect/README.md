# UI Effect

Unreal Engine 5.7 UI에서 사용하는 머티리얼 기반 이펙트 에셋 플러그인입니다.

- 버전: `1.2.0`
- 제작자: `DotheZac`
- 유형: Content 전용 플러그인

## 주요 구성

- UI 이펙트 기본 머티리얼
- 캐릭터별 Glow 머티리얼 인스턴스
- 캐릭터별 Ramp 텍스처
- Rainbow 텍스처

## 주요 에셋

- `M_UIEffect`
- `MI_GlowEffect_Heru`
- `MI_GlowEffect_Inpu`
- `MI_GlowEffect_Item`
- `MI_GlowEffect_Nefer`

## 사용 방법

플러그인을 활성화한 후 Content Browser에서 `UIEffect Content`를 표시하여 필요한 머티리얼 인스턴스를 UI에 적용합니다.
